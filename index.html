MemoPin(고정메모) 개인정보처리방침

시행일: 2026년 11월 14일

MemoPin은 별도의 개발자 서버를 운영하지 않으며, 사용자의 개인정보를 개발자에게 수집·전송하지 않습니다. 모든 데이터는 기기에 저장되며, 사용자가 직접 연결한 서비스(Google Tasks, Microsoft To Do)와만 통신합니다.

처리하는 정보

  • 메모·할 일: 사용자가 입력한 내용은 기기에만 저장됩니다.
  • 캘린더: 권한을 허용한 경우 기기 캘린더의 일정 제목과 시간을 읽어 앱과 알림에 표시합니다. 외부로 전송되지 않습니다.
  • 위치: 사용자가 장소 조건(특정 장소 도착·출발 시 알림)을 설정한 경우에만 기기 위치를 사용하며, 앱을 사용하지 않을 때에도(백그라운드) 지오펜스로 도착·출발을 감지합니다. 위치 정보는 기기 안에서만 처리되며 외부로 전송되지 않습니다.
  • Wi-Fi: Wi-Fi 연결 조건을 설정한 경우 현재 연결된 Wi-Fi 이름(SSID)을 기기 안에서만 확인합니다.
  • 지도: 장소를 고를 때 OpenStreetMap 지도 타일을 불러오며, 이 과정에서 지도 서버에 표시 중인 지도 영역과 IP 주소가 전달됩니다.
  • 음성 안내: 알림 읽어주기는 기기의 음성 합성(TTS) 엔진을 사용합니다.

Google Tasks 연동

사용자가 Google 계정을 연결하면 MemoPin은 다음 권한을 요청합니다.

  • https://www.googleapis.com/auth/tasks: 사용자의 Google Tasks 할 일 목록과 할 일을 읽고, MemoPin에서 만들거나 수정·완료·삭제한 할 일을 Google Tasks에 반영하여 양방향 동기화하는 데에만 사용합니다.
  • userinfo.email: 연결된 계정을 앱 화면에 표시하고 구분하는 데에만 사용합니다.

Google 사용자 데이터는 기기와 Google 서버 사이에서만 직접 전송되며 개발자 서버를 거치지 않습니다. 광고, 판매, 신용 평가 목적으로 사용하거나 제3자에게 이전하지 않으며, 사람이 열람하지 않습니다. MemoPin이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 이전은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

Microsoft To Do 연동

사용자가 Microsoft 계정을 연결하면 MemoPin은 Microsoft Graph의 Tasks.ReadWrite, offline_access, openid 권한을 요청하며, To Do 목록과 할 일의 양방향 동기화에만 사용합니다. 데이터는 기기와 Microsoft 서버 사이에서만 직접 전송되며 제3자에게 공유하지 않습니다.

보관 및 삭제

로그인 정보와 동기화된 데이터는 기기에만 저장됩니다. 앱에서 연결을 해제하면 동기화가 중단되고(이미 가져온 메모는 기기에 남습니다), 앱을 삭제하면 기기의 데이터가 모두 삭제됩니다. Google 계정 권한은 Google 계정 권한 페이지, Microsoft 권한은 Microsoft 앱 권한 페이지에서 언제든 철회할 수 있습니다.

공유

정보를 제3자에게 판매하거나 공유하지 않으며, 광고·분석 SDK를 사용하지 않습니다.

문의

개인정보 관련 문의는 Google Play 스토어에 표시된 개발자 연락처를 이용해 주세요.

MemoPin Privacy Policy

Effective: November 14, 2026

MemoPin runs no developer server and does not collect or transmit personal information to the developer. All data stays on the device, and the app communicates only with services the user connects (Google Tasks, Microsoft To Do).

Information processed

  • Memos and tasks are stored only on the device.
  • Calendar: with permission, event titles and times are read from the device calendar for display. This data never leaves the device.
  • Location: used only when the user sets a place condition (remind on arriving at or leaving a place), including in the background via geofences. Location is processed on the device only and never transmitted.
  • Wi-Fi: when a Wi-Fi condition is set, the connected network name (SSID) is checked on the device only.
  • Map: when choosing a place, OpenStreetMap tiles are loaded, which shares the viewed map area and IP address with the tile server.
  • Spoken reminders use the device's text-to-speech engine.

Google Tasks integration

When the user connects a Google account, MemoPin requests:

  • https://www.googleapis.com/auth/tasks: to read the user's Google Tasks lists and tasks and to write tasks created, edited, completed or deleted in MemoPin back to Google Tasks (two-way sync). It is used for nothing else.
  • userinfo.email: only to show and identify the connected account in the app.

Google user data travels directly between the device and Google; it never passes through a developer server. It is not used for advertising, sold, used for credit decisions, transferred to third parties, or read by humans. MemoPin's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Microsoft To Do integration

When the user connects a Microsoft account, MemoPin requests the Microsoft Graph permissions Tasks.ReadWrite, offline_access and openid, used only for two-way sync of To Do lists and tasks. Data travels directly between the device and Microsoft and is not shared with third parties.

Retention and deletion

Sign-in data and synced data are stored only on the device. Disconnecting in the app stops syncing (already imported memos stay on the device); uninstalling the app deletes all of its data from the device. Access can be revoked at any time at Google Account permissions or Microsoft app permissions.

Sharing

No information is sold or shared with third parties. The app uses no advertising or analytics SDKs.

Contact

For privacy questions, use the developer contact shown on the Google Play listing.
